Download the app
Android · always the latest version · about 70 MB

How to install

  1. Tap Download the app.
  2. If Chrome says “File might be harmful”, tap Download anyway. This is normal for apps shared outside the Play Store.
  3. Open the downloaded file and tap Install. Allow “Install unknown apps” if Android asks.
  4. Open BN Mullick Arena → Get Started → Create account.

Already have the app? Install over it — your data stays. The app also tells you when a new version is out.

In the app

  • Fixtures, live scores and results
  • Group tables and the knockout bracket
  • Goal scorers with the minute they scored
  • Every team and player — search by name, team or photo
  • Match and result posters, ready to share
